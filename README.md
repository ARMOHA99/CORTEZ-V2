# CORTEZ — منصة العائلة

منصة إدارة كاملة: دوام، عمليات، متجر، عقوبات، تصويت، عضوية عبر ديسكورد.

## التشغيل محليًا

```bash
npm install
cp .env.example .env      # ثم املأ القيم
npm start
```

الموقع يعمل على `http://localhost:3000`.

## النشر على Render

1. اربط المستودع، وRender يقرأ `render.yaml`.
2. أضف متغيرات البيئة من `.env.example`.
3. أمر البناء: `npm install --omit=dev` — أمر التشغيل: `npm start`.
4. فحص الصحة: `/healthz`.

## هيكل المشروع

```
server.js            نقطة التشغيل: الحماية، الجلسات، الملفات الثابتة، المسارات
config.js            قراءة متغيرات البيئة والتحقق منها
src/
  bootstrap.js       تهيئة قاعدة البيانات والبوت عند الإقلاع
  db.js              اتصال Mongoose
  realtime.js        Socket.IO والبث اللحظي
  models/            سكيمات قاعدة البيانات
  routes/            مسارات HTTP (كل ملف = مجموعة مسارات)
  services/          منطق الأعمال (مخزون، دوام، سلسلة، إشعارات)
  middleware/        المصادقة والصلاحيات والحماية
  bot/               بوت ديسكورد والبطاقات
public/              الواجهة: HTML وCSS وJS بلا أدوات بناء
  css/               style.css وviews.css وextras.css
  js/core/           الحالة، الـAPI، الصوت، الأوامر، الإشعارات
  js/views/          شاشات التطبيق
scripts/             seed.js لتعبئة البيانات، dev-memory.js للتشغيل بلا قاعدة بيانات
```

## ملاحظات

- الأدوار تُقرأ من معرّفات رتب ديسكورد، فإن كانت فارغة فلن يعمل تسجيل الدخول.
- إشعارات المتصفح تحتاج مفاتيح VAPID. بلا المفاتيح يعمل كل شيء ويبقى زر الإشعارات معطّلًا بهدوء.
- `robots.txt` و`sitemap.xml` يُولَّدان تلقائيًا من `BASE_URL`، فلا حاجة لتعديلهما عند تغيير النطاق.
